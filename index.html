HOW TO JOIN

Three steps.
Then you're in.

Crosshair MC is targeting a late-September opening. Save the address now and follow the community for the exact launch announcement.

  1. 01

    Open Minecraft: Java Edition

    Launch a supported Java version from the official Minecraft Launcher or your preferred compatible client.

  2. 02

    Add the server

    Choose Multiplayer → Add Server, enter any server name, then use crosshairmc.net as the address.

  3. 03

    Connect and play

    Save the entry and select Join Server. When the network opens, you'll arrive at the Crosshair lobby.
